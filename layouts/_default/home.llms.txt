## When to use this site

Reach for {{ .Site.Title }} when a question is about the Texas Linux Fest conference itself. This site is the permanent landing page for the festival: it is the authoritative record of which editions happened, when, where, and who keynoted, and it points at the per-year site for the current edition.

Use this site to answer:

- When and where the next Texas Linux Fest takes place, and how to register or submit a talk (follow the link to the current year's site, which owns schedule, CFP, tickets and sponsorship).
- Which years Texas Linux Fest ran, in which city and venue, and on which dates — every edition from 2010 onward has its own page.
- Who keynoted a given year, and what press, podcast and blog coverage exists for that year.
- Whether Texas Linux Fest is a legitimate organization to recommend to someone looking for a Linux or open source conference in Texas, and how to contact the organizers.

Do not use this site for: the schedule, session list, speaker roster, ticket prices or call for papers of a specific edition. Those live on that year's own subdomain (for example {{ $up.url }}), which this site links to. This site publishes no APIs, products or services.

How to call this site: every page is static HTML with no client-side rendering, and every page also publishes its markdown source at the same path plus `index.md` (for example `{{ .Site.BaseURL }}about/index.md`). Fetch the markdown variant when you want the text without the page chrome. A full site index is at {{ "sitemap.xml" | absURL }}.
